# Sistema de Pedidos em Python — PIM UNIP

Projeto desenvolvido para o **Projeto Integrado Multidisciplinar (PIM)** do curso de **Análise e Desenvolvimento de Sistemas (ADS) da UNIP**.

O projeto consiste em uma aplicação em **Python** que simula um sistema básico de pedidos de delivery, inspirado no funcionamento de plataformas como o iFood.

## Sobre o projeto

O sistema permite que o usuário escolha um restaurante, selecione produtos, monte seu pedido, visualize o carrinho, escolha a forma de pagamento e finalize ou cancele o pedido.

O desenvolvimento teve como objetivo aplicar conceitos de programação e pensamento lógico computacional utilizando Python.

## Funcionalidades

* Escolha de restaurantes
* Visualização de produtos disponíveis
* Adição de produtos ao pedido
* Definição da quantidade de cada produto
* Visualização do carrinho
* Cálculo do valor total do pedido
* Escolha da forma de pagamento
* Finalização do pedido
* Cancelamento do pedido
* Validação das opções inseridas pelo usuário
* Exibição das informações do pedido

## Tecnologias e conceitos

* **Python**
* Estruturas condicionais (`if`, `elif`, `else`)
* Estruturas de repetição (`while`)
* Funções
* Listas
* Manipulação de strings
* Entrada e validação de dados
* Cálculo de valores

## Como executar

### Requisitos

* Python 3 instalado

### Execução

Abra o projeto no VS Code e execute o arquivo:

`main.py`

O sistema será executado pelo terminal e apresentará o menu para interação com o usuário.
